## Quick Answer

Many players are asking for custom keybinds, AZERTY support, and left-handed control options. Based on current public reports, this appears to be a feature/accessibility problem rather than a confirmed local bug with one clear fix.

## Symptoms

- Players using AZERTY keyboards say the current controls are difficult or unplayable.
- Left-handed players ask to rebind movement and interaction keys.
- Some players ask whether keybinds can be changed at all.
- Multiple comments ask the developer to add keybind customization.

## What You Can Check

1. Open the in-game settings and look for control or keyboard options.
2. Check Steam discussions for current patch notes or developer replies.
3. If you use a programmable keyboard, use hardware-level remapping only if you already understand how to undo it.
4. If the game has no built-in rebinding option, treat this as a feature request rather than a normal troubleshooting fix.

## If You Use AZERTY

Do not assume a guide for QWERTY keyboard controls will map cleanly to your layout. When reading control guides, check whether the author is using QWERTY, AZERTY, or a custom layout.

## What Not to Do

- Do not install unknown key-remapping tools from random links.
- Do not edit game files unless official documentation supports it.
- Do not follow advice that cannot be reversed.
