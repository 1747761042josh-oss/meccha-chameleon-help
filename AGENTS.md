# Project Rules

## Purpose

This project is an MVP for an unofficial English MECCHA CHAMELEON help site. It is an information-organizing site, not a personally tested strategy site.

## Content Rules

- Do not claim a fix, guide, setting, or map tip is personally tested unless a test record exists.
- Use `Community Reported` for information gathered from multiple player reports.
- Use `Unconfirmed` for single reports, weak evidence, or unclear reproduction steps.
- Do not publish piracy, crack, authentication bypass, unsafe registry edits, or suspicious download instructions.
- Link to official or community sources when an article depends on them.

## Structure

- `src/pages/` contains route pages.
- `src/components/` contains reusable UI components.
- `src/layouts/` contains shared page layouts.
- `src/content/` contains Markdown content collections.
- `src/styles/` contains global styles.
- `public/` contains static assets such as `robots.txt` and favicon files.
- `data/` contains research tables, source lists, and content planning CSV files.

## Naming

- Use lowercase kebab-case for route and content filenames.
- Keep UI components in PascalCase.
- Keep content slugs short and search-oriented.

## Cleanup

- Remove temporary files before finishing a task.
- Keep generated build output out of source control.
